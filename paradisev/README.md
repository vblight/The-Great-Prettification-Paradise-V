# Paradise V — refreshed original liveries

Replace your existing `paradisev` resource folder with this folder. Add `ensure paradisev` to server.cfg if needed, then restart the resource and reconnect. Spawn: `paradisev`.

Choices 1–4 are refreshed versions of the original wave, shark, lumberjack and octopus murals. They now use 1024×512 standard textures and 2048×1024 high textures with mipmaps.

All custom textures (choices 5–18), the paint-through choice, vehicle models, metadata and commands are retained from your supplied resource. Use `/paradiselivery 1` through `/paradiselivery 18`; `/paradisecheck` should report 18.
