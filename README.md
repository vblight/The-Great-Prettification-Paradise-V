# The Great Prettification — Paradise V

A fresh look for a familiar Los Santos ride. **18 liveries** in a standalone FiveM **add-on** vehicle pack — the original GTA V vehicle stays untouched.

**Spawn name:** `paradisev`  
**Livery command:** `/paradiselivery 1–18`  
**Check command:** `/paradisecheck`

## Installation

1. Copy the `paradisev` folder into your FiveM server's `resources` directory.
2. Add `ensure paradisev` to `server.cfg`.
3. Restart the server or start the resource, then spawn `paradisev`.

This is an add-on, not a replacement. You can keep using the original vehicle alongside it.

## What's included

- Complete FiveM add-on resource in `paradisev/`
- Vehicle models, textures, metadata and livery command
- [Livery preview](previews/PREVIEW.jpg) made from the actual vehicle textures (not an in-game screenshot)
- Original pack notes and checksums inside the resource folder

The `previews/` folder is for browsing and doesn't need to be installed on your server. Livery selection persistence depends on your server's garage/vehicle system.
