# The Great Prettification — Paradise V

A refreshed look for Paradise V in FiveM. This is a add-on vehicle pack featuring 18 liveries.

## Installation

1. Download the repository ZIP or the attached resource ZIP when available.
2. Copy the FiveM resource folder into your server's `resources` directory.
3. Add an `ensure <resource-folder-name>` line to `server.cfg`.
4. Restart the resource or server and spawn the vehicle.

**Add-on spawn name:** `paradisev`. The original GTA V vehicle remains available.

**Livery command:** `/paradiselivery 1` through `/paradiselivery 18`.
